# KIT-Assisted Open-Source Codebase Sweep

This repository contains the technical report for a two-week, KIT-assisted security review campaign across 158 assigned open-source repository entries.

The report covers campaign scale, review method, human supervision, evidence limits, and one critical Langflow case study backed by an exact reviewed commit.

- [Read the report](REPORT.md)
- [Review the source anchors](SOURCES.md)

The repository omits exploit code and private campaign artifacts. Findings apply to the revisions identified in the source register and should be revalidated against current releases.
